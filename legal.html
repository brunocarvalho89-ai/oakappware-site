Privacidade do site · Website privacy

O que o site oakappware.com trata
What the oakappware.com website processes

Este site é estático: não usa cookies, não tem analytics nem rastreadores e não coleta formulários.

This website is static: it uses no cookies, has no analytics and no trackers, and collects no forms.

A hospedagem (GitHub Pages) pode registrar dados de acesso, como endereço IP e user agent, para operação e segurança do serviço, pelo prazo do provedor.

The hosting provider (GitHub Pages) may log access data, such as IP address and user agent, for the operation and security of the service, for the period set by the provider.

Os e-mails enviados a contato@oakappware.com são usados apenas para responder ao contato.

E-mails sent to contato@oakappware.com are used only to reply to the contact.
